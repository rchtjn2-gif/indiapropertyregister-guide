# India Property Register

**Every village, plot and property in India.** Official site: [indiapropertyregister.com](https://indiapropertyregister.com/)

India Property Register is a register of land and property in India. Land is a state subject, so its data sits in hundreds of separate government portals: records of rights, cadastral maps, registration and encumbrance records, RERA, circle rates, municipal property tax, the Local Government Directory and notices from banks, courts, tribunals and the Gazette. The register places each source on the same spine of LGD codes and plot numbers, so everything known about a plot lands on its one page, with the source and date of every fact. You can browse states, districts, tehsils and villages, find plots by khasra, survey, gat or khata number, search holder names, read circle rates, see bank auction properties and RERA projects, and check notified land. A page is not proof of title or a certified copy. Developers can use the API and MCP server.
